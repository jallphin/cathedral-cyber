# Cathedral Cyber — Business Card Print Files

## Files
- `business-card-front.svg` — Logo, tagline, URL
- `business-card-back.svg` — Name, title, credentials, contact info

## Specs
- **Size**: US standard 3.5" × 2" plus 0.125" bleed on all sides
- **Canvas**: 3.75" × 2.25" (1125 × 675 px at 300 DPI)
- **Color mode**: RGB — convert to CMYK in your print vendor’s workflow if required
- **Safe area**: keep critical text/logo inside the inner gold frame
- **Fonts**: Inter, Space Grotesk, JetBrains Mono. Convert to outlines before sending to a printer if you want guaranteed fidelity.

## How to use
1. Open both SVGs in Illustrator, Inkscape, or Affinity Designer.
2. Embed the linked images (`wordmark.png`, `icon.png`) so they travel with the file.
3. Convert text to outlines (optional but recommended).
4. Export as PDF/X-1a or PDF/X-4 for the print shop.
