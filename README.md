# Cathedral Cyber

Astro static site for Cathedral Cyber — red team operations, penetration testing, and adversary simulation for defense contractors and federal agencies.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Output is written to `dist/`.

## Deployment

Deploy the `dist/` folder to GitHub Pages. The `astro.config.mjs` uses `base: '/cathedral-cyber'` for project-page hosting.

## Design Direction

Gothic minimalism: stone-dark palette, 1px stone borders, restrained gold accent, Space Grotesk + Inter + JetBrains Mono, generous negative space, no neon or ornate decoration.
